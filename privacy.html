Kebijakan Privasi

Aplikasi Saku PBJ · PT Pertamina Retail · Berlaku sejak 2 November 2026

1. Tentang aplikasi

Saku PBJ adalah buku saku dan alat bantu untuk Fungsi Peminta Pengadaan (FPP) PT Pertamina Retail. Aplikasi ini berisi ringkasan Pedoman Pengadaan Barang/Jasa, TKO, checklist, kalkulator, dan chatbot Tanya Saku.

2. Data yang kami kumpulkan

  • Saat masuk dengan Google: alamat email, nama tampilan, dan ID akun Google. Data ini hanya dipakai untuk memeriksa apakah email Anda terdaftar sebagai pengguna yang boleh mengakses aplikasi.
  • Saat menggunakan Tanya Saku: teks pertanyaan yang Anda ketik. Pertanyaan diteruskan ke layanan AI untuk dijawab.

Kami tidak menggunakan iklan, tidak menjual data, dan tidak memakai data untuk pelacakan lintas situs.

3. Penyimpanan dan pihak ketiga

  • Daftar pengguna yang boleh login disimpan di Google Sheet milik admin Fungsi Procurement, dan hanya dikelola oleh admin.
  • Pemeriksaan login dilakukan melalui Google Apps Script dan layanan Google Identity.
  • Pertanyaan chatbot diteruskan melalui server perantara (Cloudflare Workers) ke layanan AI pihak ketiga. Mohon tidak mengetik data rahasia seperti nilai HPS atau data pribadi di kolom Tanya Saku.

4. Penyimpanan di perangkat Anda

Aplikasi menyimpan status login dan riwayat chat di browser perangkat Anda (localStorage) agar Anda tidak perlu login ulang. Anda dapat menghapusnya kapan saja dengan menghapus data situs dari pengaturan browser, atau memakai tombol keluar di aplikasi.

5. Hak Anda

Anda dapat meminta agar akses Anda dicabut atau data Anda dihapus dari daftar pengguna dengan menghubungi admin Fungsi Procurement.

6. Perubahan kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Perubahan akan ditampilkan di halaman ini.

7. Kontak

Pertanyaan tentang kebijakan ini dapat disampaikan kepada admin Fungsi Procurement PT Pertamina Retail.
