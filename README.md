# Saku PBJ — Buku Saku Pengadaan Barang/Jasa PT Pertamina Retail

Aplikasi web (PWA) berisi ringkasan **Pedoman Pengadaan Barang/Jasa** (No. A-002/B24000/2023-S9) serta tiga TKO: **Pemilihan Penyedia** (B-008), **Registrasi & Update Data Penyedia** (B-004), dan **Penilaian Kinerja & Koreksi Sanksi** (B-003). Dilengkapi diagram proses, checklist FPP per paket, dan kalkulator pengadaan (termasuk simulasi poin kinerja penyedia).

**Buka aplikasi:** https://readdyaria-alt.github.io/saku-pbj/

- Android (Chrome): tekan **Pasang aplikasi** di Beranda.
- iPhone (Safari): **Bagikan → Tambahkan ke Layar Utama**.

Panduan lengkap ada di [PANDUAN-INSTAL.md](PANDUAN-INSTAL.md). Ringkasan ini bukan pengganti dokumen asli.
